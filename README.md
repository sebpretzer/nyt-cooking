# nyt-cooking

[`nyt-cooking`](https://nyt-cooking.pretzer.io/) is an (unofficial) Python client and MCP server for [NYT Cooking](https://cooking.nytimes.com/). It requires an NYT Cooking subscription.

Check out the [documentation](https://nyt-cooking.pretzer.io/) for more information.
