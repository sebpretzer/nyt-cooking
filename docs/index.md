# nyt-cooking

A Python client and MCP server for [NYT Cooking](https://cooking.nytimes.com/). It requires an NYT Cooking subscription.

It can search recipes, read recipes and their comments, and manage your recipe box and folders. The same operations are available as a Python client and as MCP tools.

See the [reference](reference/client.md) for the full API.
